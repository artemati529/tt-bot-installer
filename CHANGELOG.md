## [1.0.0] — 2026-09-23

Первый релиз.

### Бот (`bot.py`)
- Пользователи VPN: добавление (со случайным префиксом или без), смена
  пароля, удаление, выдача QR, deeplink и клиентского TOML-конфига,
  поиск и постраничный список с фильтром онлайн/оффлайн.
- Отмена последнего действия (удаление, смена пароля, восстановление) —
  кнопка привязана к своему действию и не затирает более поздние правки.
- Бэкап и восстановление конфигов (`vpn.toml`, `hosts.toml`,
  `credentials.toml`, `rules.toml`, карта префиксов, профили) с
  откатом при сбое применения; `/diff` против последнего бэкапа с
  маскировкой паролей.
- Синхронизация `rules.toml` с пользователями: поиск и удаление
  лишних allow-правил, восстановление недостающих.
- Сервер: перезапуск TrustTunnel, обновление TrustTunnel и ОС в фоне,
  перезагрузка, карточки «Нагрузка», «Клиенты VPN», сертификат
  (certbot.timer, лог), журнал сервиса с фильтрами.
- Доступ только у `ALLOWED_USER_ID` и только в личном чате; аргументы
  с именами пользователей не попадают в журнал.

### Установщик (`install.sh`)
- Ставит бот поверх уже настроенного TrustTunnel: venv, зависимости,
  `.env` (права 0600), `tt-bot.service`; по желанию выпускает
  сертификат через certbot и прописывает его в `hosts.toml`.
- Безопасен для `curl | bash` (оборванная загрузка ничего не выполняет)
  и для повторного запуска (прежний `.env` сохраняется, ручные ключи
  переносятся, бот перезапускается).

### Качество
- 521 тест (pytest), ruff, mypy, vulture, shellcheck; CI на GitHub
  Actions для Python 3.11 и 3.12.
